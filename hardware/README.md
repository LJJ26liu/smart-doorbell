# 硬件设计文档

> 项目：ESP32-S3 智能门铃系统  
> 最后更新：2026年8月


## 一、硬件外设清单

| 设备 | 型号 | 数量 | 关键参数 | 功能说明 |
|------|------|------|---------|----------|
| **开发板** | ESP32-S3-DevKitC-1 | 1 | 主控：ESP32-S3（Xtensa LX7 双核 240MHz）<br>Flash：8MB（W25Q64）<br>PSRAM：8MB<br>WiFi 802.11 b/g/n、BLE 5.0 | 系统主控，负责图像采集、AI推理、网络通信、外设控制 |
| **摄像头模组** | OV2640 | 1 | 传感器：CMOS 200万像素<br>最大分辨率：1600×1200 (UXGA)<br>输出格式：JPEG / YUV / RGB565<br>接口：DVP 并行 | 采集图像，输出 JPEG 格式照片，用于AI行人检测和云端上传 |
| **人体红外传感器（PIR）** | HC-SR501 | 1 | 工作电压：DC 4.5-20V<br>输出电平：高3.3V / 低0V<br>感应封锁时间：2.5s<br>触发方式：L=不可重复 / H=可重复 | 检测人体移动，触发摄像头抓拍 |
| **蜂鸣器（无源）** | 无源蜂鸣器模块 | 1 | 工作电压：3.3V-5V<br>驱动方式：PWM<br>频率范围：2kHz~5kHz | 门铃按键触发时播放《小星星》旋律 |
| **门铃按键（外接）** | 自复位轻触开关 | 1 | 按下拉低电平，带机械弹力复位 | 门铃外部物理按键，按下触发蜂鸣器旋律 |


## 二、GPIO 引脚接线表

| 外设 | 功能 | GPIO 引脚 | 备注 |
|------|------|-----------|------|
| **OV2640 摄像头** | PWDN（掉电控制） | GPIO17 | 低电平有效，可接 GND 使能 |
| | RESET（复位） | GPIO16 | 高电平工作，可接 3.3V |
| | XCLK（主时钟输入） | GPIO21 | 需提供 20MHz 时钟 |
| | SIOD（SCCB 数据线） | GPIO15 | I²C 数据，需上拉 |
| | SIOC（SCCB 时钟线） | GPIO14 | I²C 时钟，需上拉 |
| | D7 | GPIO10 | 并行数据位 D7 |
| | D6 | GPIO9 | 并行数据位 D6 |
| | D5 | GPIO8 | 并行数据位 D5 |
| | D4 | GPIO7 | 并行数据位 D4 |
| | D3 | GPIO6 | 并行数据位 D3 |
| | D2 | GPIO5 | 并行数据位 D2 |
| | D1 | GPIO4 | 并行数据位 D1 |
| | D0 | GPIO3 | 并行数据位 D0 |
| | VSYNC（场同步） | GPIO11 | — |
| | HREF（行参考） | GPIO12 | — |
| | PCLK（像素时钟） | GPIO13 | — |
| **PIR 传感器** | 信号输出 | GPIO18 | 输入，内部下拉，高电平表示检测到人 |
| **内置 BOOT 按键** | 按键输入 | GPIO0 | 按下低电平，已内部上拉 |
| **门铃按键（外接）** | 按键输入 | GPIO39 | 按下低电平，已内部上拉 |
| **无源蜂鸣器** | PWM 驱动 | GPIO40 | 输出，低电平鸣叫 |
